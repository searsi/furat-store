# متجر فرات الصياد V1.0

## تجربة محلية
شغل `python -m http.server 8000` داخل المجلد وافتح http://localhost:8000 . صفحة admin.html تعمل محلياً دون تسجيل دخول في الوضع التجريبي فقط. البيانات التجريبية تحفظ في المتصفح ولا تتزامن بين الأجهزة.

## إعداد النشر الحقيقي
1. أنشئ مشروع Firebase مستقلاً وأضف Web App وانسخ إعداداته إلى config.js.
2. أنشئ Firestore Database بوضع Production.
3. فعّل Authentication > Email/Password وأضف مستخدم فرات ببريد حقيقي وكلمة مرور قوية. انسخ UID من قائمة المستخدمين.
4. استبدل REPLACE_WITH_ADMIN_UID في firestore.rules بالـ UID ثم انسخ القواعد إلى Firestore > Rules وانشرها. لا تستخدم قواعد مفتوحة للكتابة.
5. ارفع محتويات المجلد إلى مستودع GitHub جديد. Settings > Pages > Deploy from a branch > main > / (root).
6. أضف نطاق GitHub Pages إلى Firebase Authentication > Settings > Authorized domains عند الحاجة.
7. افتح admin.html وسجل الدخول واضبط رقم واتساب فرات بصيغة 9647XXXXXXXXX بدون +. أضف المنتجات الحقيقية والصور والأسعار. قاعدة البيانات الجديدة تبدأ دون منتجات.
8. اختبر الطلب من جهاز آخر. واتساب يفتح رسالة جاهزة وعلى الزبون ضغط إرسال. لا توجد قاعدة بيانات للطلبات أو دفع إلكتروني. أجور التوصيل بالاتفاق.

الصور تضغط وتحفظ داخل Firestore، لا تحتاج Storage. المنتجات المخفية لا تظهر في واجهة المتجر لكنها قابلة للقراءة من قاعدة البيانات؛ لا تضع معلومات سرية فيها. لا تنشر الوضع التجريبي للزبائن. لا تضع كلمة مرور أو مفتاح حساب خدمة في config.js. إعداد Firebase العام ليس مفتاحاً سرياً؛ الحماية بالقواعد.
